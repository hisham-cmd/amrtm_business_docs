## خيار أفضل إن أردت

| الخيار | النتيجة |
|---|---|
| **احتفظ بالأسرار خارج Git** | الفريق يرى التوثيق، ولا أحد يرى كلمات المرور |
| **شيفّرها** (`.age` / GPG) | في المستودع، والمفتاح وحده خارج Git |
| **مدير أسرار** (Vault / Doppler / Infisical) | تدوير دوري وم records وصول |
| **سيرفر CI** | الأسرار في متغيرات بيئة CI، والمستودع نظيف |

القوالب `*.example.cfg` و`*.example.php` تكفي للفريق للبدء.
