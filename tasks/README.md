## معايير التقييم المشتركة

كل مهمة تُسلَّم وفقاً للمعايير التالية:

| المعيار | النسبة | أداة التحقق |
|---------|:------:|-------------|
| `php artisan test` — كل الاختبارات PASS | 30% | PHPUnit |
| `php artisan view:cache` — يمر | 10% | Artisan |
| `npm run build` — يمر | 10% | Vite |
| لا `<input>` / `<button>` خام (مكوّنات UI) | 15% | فحص يدوي |
| التصميم متوافق مع Corporate-UI | 15% | مراجعة كود |
| Responsive على 3 مقاسات | 10% | DevTools |
| لا أخطاء Console في المتصفح | 5% | Console |
| Clean Code (لا تكرار، ملفات منفصلة) | 5% | مراجعة كود |

## المتطلبات المشتركة

كل مهمة تعتمد على المكونات والبنية التحتية التالية:

### مكونات UI المطلوب استخدامها
```
<x-ui.button>     — للأزرار
<x-ui.input>      — للحقول النصية
<x-ui.select>     — للقوائم المنسدلة
<x-ui.textarea>   — للنصوص الطويلة
<x-ui.badge>      — للشارات
<x-ui.card>       — للبطاقات
<x-ui.chips>      — لأزرار التبديل
<x-ui.modal>      — للمودالات
<x-ui.checkbox>   — للمربعات
<x-ui.eye-field>  — لكلمات المرور
<x-ui.label>      — للتسميات
<x-ui.pagination> — للصفحات
```

### بنية التصميم
```css
/* الألوان */
--cui-primary: #006C35
--cui-primary-soft: #E9F3EC

/* الحدود */
border border-[--b1]     /* #DBE6DF */

/* الزوايا */
rounded-2xl              /* 1rem */
rounded-xl               /* 0.75rem */

/* الظلال */
shadow-[0_4px_24px_rgba(0,0,0,0.06)]
```

### الهيكل الأساسي لكل صفحة
